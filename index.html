How multiplayer works:
• LAN / Same PC: Hosting uses BroadcastChannel — any tab hosting appears instantly in server list as ONLINE. Up to 10 tabs = 10 players, no internet needed. Perfect for testing.
• Internet: Uses PeerJS cloud (0.peerjs.com). Host gets a Peer ID, share it or it appears in list if both on same browser profile? For internet cross-PC, use Direct ID join. Host ID is shown after hosting.
• Sync: Deterministic terrain (same seed), only block changes + player positions are synced. Host relays.
• Limit: Host enforces 2-10 players.
